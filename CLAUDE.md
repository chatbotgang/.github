# .github — Organization Profile

This repo serves as the GitHub organization profile for [`chatbotgang`](https://github.com/chatbotgang).

Its primary purpose is `profile/README.md`, which directs visitors to [awesome-cresclab](https://github.com/chatbotgang/awesome-cresclab) — the central index of all repositories.

It also hosts organization-wide engineering guides under `docs/`:

| Guide | Scope |
|-------|-------|
| [`docs/api-documentation-guide.md`](docs/api-documentation-guide.md) | How every service documents its HTTP API — spec ownership, per-stack generation, conventions, review checklist |

Keep `profile/README.md` minimal; it is the public-facing org page. Guides in `docs/` are for engineers across the organization and should be linked from the root `README.md`.

## Language

- Code & documentation: American English
